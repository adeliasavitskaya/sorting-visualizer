Разбивает подмассив [l..r] на две части по схеме Ломуто

Pivot — правый элемент arr[r]. После выполнения pivot стоит на своей финальной позиции: все элементы слева меньше или равны ему, все элементы справа — больше. Записывает шаг COMPARE при каждом сравнении и шаг SWAP при каждом обмене.

Финальный индекс pivot после разбиения

Рекурсивный помощник быстрой сортировки

Записывает шаг FIND_PIVOT, вызывает partition, затем рекурсивно сортирует левую [l..p-1] и правую [p+1..r] части. Pivot исключается — сужение диапазона гарантировано.
