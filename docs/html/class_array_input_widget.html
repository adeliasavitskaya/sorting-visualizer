Detailed Description

Виджет ввода массива для визуализатора сортировок

Позволяет пользователю ввести числа через пробел или сгенерировать случайный массив. Проверяет корректность ввода и отправляет сигнал arrayReady когда массив валидный. Максимальная длина массива — 20 элементов.
